# 任务资源组合与运行诊断

任务的 `toolPolicy` 和上下文的 `config.tools` 支持 `packages`、`sources`：

```json
{
  "packages": [{"id":"math_one","operations":["package_math_one_calculate"]}],
  "sources": []
}
```

`null` 或省略沿用上级；任务沿用上下文，上下文沿用全局。空数组明确不授权。显式实例必须同时列出操作，新增实例或操作不会扩大这种授权。原有配置省略字段时保留原有有效能力。导出保留这些字段，配置导入先验证实例与操作，再在配置事务内应用。

每次运行从当前任务及上下文确定资源授权，并把继承的全局资源展开成 `toolPolicy.resourceGrants` 写入历史快照。物理会话的提示词可以定格，资源授权仍逐次重算。Agent 的工具目录和实际 dispatcher 均使用该次授权；手填未授权 ID 或操作会被拒绝。显式资源范围关闭旧固定资源入口、`yu_admin` 和暂未证明可继承资源范围的委派/工作流入口。管理台“管理员全局试运行”使用管理身份，不冒充某个任务。

统一依赖图位于 `GET /api/resources`。`GET /api/resources/:kind/:id/impact` 区分明确绑定、从明确绑定继承、全局继承范围、近期实际调用和可由历史快照确认的正在使用的运行。全局继承范围跟随全局启停，不作为永久强依赖。近期调用仅为观测，不能证明当前绑定。

资源影响面板支持明确替换或解除全部绑定，再执行删除/停用。`POST /api/resources/:kind/:id/change` 接受 `action`（`delete` / `disable`）、`resolution`（`protect` / `replace` / `detach`）、`replacementId`。停用适用于工具包和数据源；被使用的上下文必须替换。明确绑定默认保护，替换/解除及注册清单写入在同一事务中；失败恢复配置和运行目录。触发规则替换保持绑定 ID、同类型 webhook 的既有口令，按新规则重置调度。原文件和数据库资料默认保留，正在执行的适配器沿用已有取消行为。

运行详情入口为 `/runs/:id`，任务历史和今日列表均可跳转。页面依据当次快照、步骤、业务/归档提交标记及按 run ID 查询的实际工具调用显示诊断；旧记录没有证据时显示未记录。当前任务配置仅用于跳转，不替代历史。运行诊断与依赖影响响应在后端统一遮蔽凭据字段、已知敏感值及 Bearer 等凭据文本；普通参数和结果可在详情中折叠查看。

本阶段不新增自动重试，避免把已提交的业务重复执行。触发组合、便携包和外部插件 SDK 不在本次变更中。

验证：`test/resource-composition.test.mjs` 覆盖继承/空选择、两 agent 的目录与调用隔离、guest 范围保留、敏感遮蔽与计数保留、资源多引用原子替换/解绑、失败回滚与运行目录恢复、导入拒绝坏引用、触发绑定与口令保留、真实 runner 历史授权快照不随当前配置改变。独立真实 DSH 与 headless 验收记录见本次发布验收文档。
