# 配置语义与验收

JSON 是 `mode: "merge"`：省略领域或实体保留现状；同名任务、上下文、渠道更新，项目按 id，触发器按 type+label。每个传入实体是完整定义（字段缺省按该领域默认值），渠道 config 为键级合并，工具覆盖 config 整体替换。注入 sections 与项目 state 明确传入时整体替换。未知顶层/实体字段或设置、重复标识、缺失任务上下文/项目引用会拒绝整份应用；工具 config、项目 state、渠道 config 是可扩展对象，不验证第三方扩展键。

默认不导出 SMTP、webhook、渠道凭据。勾选包含凭据才完整迁移；SMTP 的 `secrets` 空字符串/null 清除；渠道 config 的空字符串/null 清除对应键。省略凭据保留目标值，新 webhook 自动生成令牌。含凭据 JSON 是密码文件。JSON 不包含 DSH 的模型供应商 API 密钥、进程监听地址和数据根；这些属于宿主/启动配置。`cordis.patch.yml` 负责启动配置，API 密钥在独立 DSH 设置中填写。

设置→配置→清空运行配置会重置所有 settings（含人格提示及注入布局）到发布内建默认，额外关闭自动记忆维护，删除任务/触发器/渠道凭据/工具覆盖/上下文/项目定义和数据根 JSON。软删除任务/上下文以保留历史引用；重启不会重建默认任务。它保留独立人格文件、短期记忆块、长期记忆、聊天、归档与设备登录。清空后不能撤销配置，请先下载备份。旧数据库备份或用户自行下载的含密钥文件不会被删除。

项目进度在 SQLite 业务存储保存。`GET /api/projects` 的 `savedProgress` 可检查；恢复时导入 `{"projects":[{"id":"原项目id","name":"恢复项目","kind":"reading"}]}`，省略 state 即恢复该 id 的进度。显式 state 则以输入为准。该进度在数据库备份中，不随普通配置导出迁移。

数据库写入整份事务提交，失败回滚且刷新设置缓存。提交后的调度、渠道同步或文件失败返回 warnings，管理台展示，不能当作连接成功。渠道 token/config 修改会重建适配器；连接是否成功到接入页检查。立即生效：数据库、渠道适配器与调度；下一次运行/下一个会话：提示、记忆、任务；重启：工具开放范围和工具注册。

## 冻结版本的配置往返

JSON 另外包含 initialization（初始化模式与七项角色名称引用）和 libraryPolicies（长期记忆库的启用、检索及自动积累策略）。接入、任务与角色通过稳定名称恢复引用，避免清空后新 ID 使触发规则断开。上下文的显式 libraryIds: [] 表示不检索任何库；省略或继承仍遵循上下文默认。

导入已有 DSH 会话模式的配置后，业务保持暂停，需在初始化页重新选择当前宿主会话并授权历史；不会继承另一安装的历史授权或首次构建完成状态。Yu 管理模式可恢复初始化选择，但实际接入连接、模型供应商与外部资料路径仍需在目标机器确认。个人记录、外部原文件和宿主 API 密钥须单独备份，不由此 JSON 迁移。
