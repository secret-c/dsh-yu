# 资源与任务的组合

Yu 的触发规则、注入资源、工具包、数据源是可复用资源。任务引用资源；原有五块记忆、明日方舟数据和默认任务是兼容配置，不是新任务必须采用的结构。普通工具包的安装、命名实例和适配扩展见 [工具包说明](TOOL-PACKAGES.md)。

## 注入资源

「注入」每条静态资源映射一个 UTF-8 文件。`source.path` 相对数据目录解析，也支持用户明确填写的绝对路径；`source.format` 当前仅支持 `utf8`。文件正文是实际来源，数据库保存资源名称、ID、文件映射、投递通道、每会话/每轮时机、字符预算及模板。文件缺失、不可读、超过 2 MiB 或不是文件会报告问题，不回退旧数据库正文。编辑页面使用文件哈希拒绝覆盖其他编辑器的新内容。移除资源定义保留文件。

升级时核心、角色卡、自定义段保存为 `injections/<id>.md`，旧记忆聚合段拆为每块独立资源，沿用 `memory/short-term/<slug>.md`。记忆维护继续产生文件，通过同一通用文件注入通路进入模型；任务可以只使用自己的任意文本资源。旧上下文的记忆筛选仅在继承资源时兼容执行，显式选择资源后以选择为准。

任务页直接选择注入资源。`task.injection: null`（省略同义）继承上下文，`context.config.injection: null` 继承全局启用资源；`[]` 表示不选择任何资源。列表形如：

```json
[{"id":"sec_worknotes","order":10,"maxChars":2000,"scope":"turn","channel":"history","template":"工作资料：\n{{content}}"}]
```

模板支持 `content`、`name`、`title`、`slug`；预算单位为字符，0 不注入。选择和覆盖适用于资源列表中的动态长期检索；显式空列表不会偷偷检索/注入长期记忆。会话资源在会话创建时冻结；每轮资源下轮直接读文件。新鲜预览和实际运行共享编译器，历史快照只显示当时已发送的内容。预览结果的 `injectionSelection` 标明最终选择来自任务、上下文还是默认资源。

## 触发规则

旧任务触发器会原位加入规则库，每个绑定得到稳定独立定义，不按参数相似度自动合并。绑定 ID、webhook 令牌和等待时刻保持不变；同一规则可被多个任务显式引用。共享参数在规则库编辑，任务保留自己的启停状态与运行时刻。删除仍被引用的定义会被拒绝。

## 配置迁移

JSON 导出包含资源元数据、`inject.contents` 的文件正文、任务/上下文的注入绑定和设置中的数据源清单。绝对注入路径默认转换为可移植的 `injections/<id>.md`。`mode: "merge"` 按现有对象合并，触发库按 ID 合并；`mode: "replace"` 在事务内清空运行配置再应用完整文档。`inject.sections: []` 明确移除全部注入定义，清空配置也不会恢复隐藏的注入资源。

导入校验引用和数据源适配器，文件写入失败时回滚配置及已改动的注入文件。清空配置/卸载数据源与删除用户资料分开；保留记忆、文档、对话、归档和源文件。导出文件正文可能包含私人信息，请按实际内容决定如何分享。

数据源适配器的安装、加载与卸载及支持边界见管理台「工具」的数据源区域。未知数据库格式需要相应适配器，不能通过改文件后缀实现通用接入；不会下载执行外部脚本。
