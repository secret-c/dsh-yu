# 上下文方案

在「上下文」选择方案，使用唯一的「注入」区域选择资源、顺序、投递方式和读取时机。继承（`injection: null`）使用全局启用资源；自选空列表（`[]`）不选择资源。任务的自选列表可覆盖方案。每会话资源仍在新会话读取，每轮资源在下一次请求读取。

「固定上下文说明」是方案每次被使用时附带的文字，单独作为 `yu:context-instructions` 注入；任务目标作为 `yu:task-rules` 注入。二者每轮读取，适用于 Yu 任务、网页接续和关联的原生会话。旧自定义风格正文保留，作为方案附加文本单独注入。

旧 `memory.mode/slugs` 是短期记忆文件块筛选，并非聊天记录。启动升级或保存方案会把非默认筛选与 `turnSections` 转成同一套资源绑定，保留明确的 `[]`；没有旧覆盖时继续保持继承。升级追加配置版本，原配置仍在历史版本中，文件正文不覆盖。

项目状态自动注入已停用，包括旧会话定格中的 `yu:project` 段。项目资料、进度和文件保留，由工具按需读取；旧 `projectProgress` 标志在升级/保存后停用。自定义文本中写到项目的内容不会删除。

原「短期记忆滑窗」中的历史策略和轮数从未控制宿主消息，不再提供无效表单。兼容 JSON 中的 `history.mode/maxTurns/compaction` 不执行消息裁剪；聊天历史由会话管理。`history.contextBudget/overLimit` 仍用于编译材料预算检查。
