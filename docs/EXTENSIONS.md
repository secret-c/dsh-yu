# 自定义记忆、知识库与接入

所有新增运行设置均在「设置 → 全部运行设置」；记忆项也在「记忆 → 记忆设置」。配置JSON导入、导出、清空包含这些设置。设置里的JSON字段必须是有效JSON，保存失败会显示具体错误。

## 记忆管理

新安装默认关闭模型维护（`memory.maintenanceStrategy=disabled`），每晚维护和每轮吸收也关闭；不配置模型密钥仍可使用管理台。已有安装首次升级时，如果已有任务而没有保存策略，沿用 `legacy` 五块预设，并保留旧的每日维护默认行为；已保存的显式设置不覆盖。清空运行配置后使用新默认，不再自动迁回旧策略。

- `legacy`：原近期经历、人物、进行中、想法、状态五块的可选预设。
- `custom`：先在「短期记忆」创建自己命名的块，再将slug填入 `memory.managedSlugs`，例如 `["work","friends"]`。维护模型只得到这些块的输出契约；验证和提交使用相同列表。未选择的块完整保留。空数组表示只提取长期事实。
- `disabled`：包括手动维护在内全部跳过，不调用模型，不消费归档。

`memory.maintenancePrompt` 可填写自己的维护说明；留空使用通用事实整理说明。动态JSON契约始终附在说明后，约束输出只有所选块。预览与真实执行共用说明和材料构造。模型不能凭输出增加块。维护期间发生人工修改会由revision冲突保护。

`memory.rules.enabled` 可关闭原内置去重、过程清理与增长控制；仍执行JSON结构、字符上限与敏感信息验证。各条规则也可单独配置。注入与自动维护独立：关闭维护不会关闭注入，块的启用开关只决定是否注入。

`memory.injection` 为逐块预算和模板，例如：

```json
{"work":{"maxChars":2000,"template":"### {{name}}\n{{content}}"},"private":{"maxChars":0}}
```

预算单位为字符，0关闭该块注入；模板支持 `{{name}}`、`{{slug}}`、`{{content}}`，整体注入上限14000字符。注入段的顺序、通道、每会话/每轮时机仍在「注入」页配置。会话冻结的段落需换新会话后更新；每轮段落下一轮更新。人工删除全部块后重启不会强制复活五块。

## 自有知识库

「记忆 → 文档库」顶部可以新增具名库、编辑名称和分类、独立启停、移除定义并保存。每个库有唯一id和唯一category，文档按category归属；选中一个库后新建文档会使用该分类。默认 `*` 库承接没有专属库的旧分类，避免隐藏已有文档。具体分类的启停优先于默认库，不能通过默认库绕过停用。

移除库定义不会删除任何文档；若存在默认库，相关文档回归默认库。管理台可查看全部文档（含停用与未归属）。独立删除文档仍需文档删除操作。库定义以 `tools.documentLibraries` JSON数组保存，例如：

```json
[{"id":"default","name":"默认文档库","category":"*","enabled":true},{"id":"work","name":"工作资料","category":"work","enabled":true}]
```

`yu_document_search` 对启用库做真实关键词检索并返回来源片段，支持 `libraryId` 限定；`yu_document_read` 支持slug和分页，也校验库归属与启用状态。未知或停用库返回错误，不回退全库。空库列表不检索任何文档。库增删启停立即影响工具执行。

`tools.documentsEnabled` 控制通用检索工具的注册，默认开启；`tools.exposure=none` 会关闭全部Yu工具。明日方舟和Tomimi均为独立可选工具，发布默认关闭，需自行准备数据、打开相应开关并选择 `tools.exposure=all`。工具注册开关、暴露级别与领域数据路径改动需重启插件；管理台会说明。文档内容更新无需重启。

## 通用OneBot接入

接入页新增「OneBot v11（反向WS）」类型，复用NapCat/SnowLuma已有的真实适配器：在兼容客户端配置 `ws://Yu地址/onebot/连接id` 与相同访问令牌，随后自行启动与登录客户端。支持v11消息事件与 `send_private_msg` / `send_group_msg` 动作；这不是任意平台协议桥。

缺失或错误令牌拒绝连接；selfId可选，填写后校验客户端声明。连接配置保存后由渠道管理器重新同步，无需重启插件。连接测试检查配置，只有客户端真实连入后才显示已连接。测试中的协议客户端能验证握手、去重和回复，但不代表用户的真实平台账号已接通。

## 框架更新（2026-10-30）

本文上面的memory聚合注入和旧方舟开关说明为兼容历史。当前静态注入全部以资源文件为正文来源，旧记忆段拆成逐文件资源，任务可直接选择并覆盖预算、模板和时机；详见[框架说明](FRAMEWORK.md)。旧tools.knowledgeDbPath仅首次迁入数据源manifest，旧开关不再作为管理入口。外部库在工具页安装、加载/停用和卸载，不需重启；源文件保留且卸载后不自动恢复。支持边界见[数据库适配器](../DATABASE-SOURCES.md)。
