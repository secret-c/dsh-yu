# Yu Companion

Yu 主要为 DeepSeek Harness 的现有会话提供关联监听、规则触发与任务投递。DSH 保有会话、Agent、模型和历史；Yu 仅管理关联、触发条件和处理记录。既有 Yu 独立会话、上下文、记忆、归档和消息渠道继续兼容。要求 Node >=22；关联适配基于 DSH 0.2.1-rc.5 公共会话接口，缺少接口时显示不可用。后端仅使用 Node 内建模块，前端已构建。

安装方式与数据目录见 [安装说明](INSTALL.md)。此源码快照不包含用户数据；运行中导入的个人资料独立保存。

## 关联 DSH 会话

在「关联 DSH 会话」选择本机宿主会话。选择列表只读元数据；只有已关联对象读取消息。首次关联和从暂停恢复从当前事件边界开始，不用旧历史触发规则。关联本身不发送 prompt，也不创建或 fork 会话。

任务的执行目标选择「发送到关联 DSH 会话」后，任务目标与输入模板组合为带 Yu 来源标记的普通消息，直接交给原 DSH 会话。定时、随机与监听规则共用此目标。原会话继续使用自己的 Agent、人设、工具、模型及工作目录；Yu 的注入与工具选项不参与这类投递。忙时可跳过，或仅保留最新未发送消息。宿主接受只表示接收入队，不表示模型执行完成；处理记录显示 accepted 等投递状态。

监听用户消息，或正常完成轮次的最后一条 AI 文本回复；工具步骤与流式片段不触发。Yu 投递的 requestId 与轮次来源用于抑制自身消息和因果回复的循环。预览最多保留最近六条，每条最多 12000 字符；处理日志保留来源、字符数、原因与安全错误摘要，不复制正文到日志。

事件游标和投递意图持久保存，重连通过分页补齐；不确定宿主是否收到的投递标为 uncertain，不自动重发。宿主 prompt 与 Yu 存储之间没有跨进程事务，因此这里提供避免重复的保守恢复，而不承诺 exactly-once。归档、删除、不可访问或写入占用不会强抢锁或改用新会话。暂停或解除关联取消尚未发送队列；已被宿主接收的消息由 DSH 继续处理。解除会保留待重新关联的目标记录，停用其规则和引用任务；明确重关联后，任务与规则仍需手动启用。解除和清空配置不删除、归档或销毁原会话。

这是同一宿主下本机所有者通过配对管理台管理的功能，不实现其他 DSH 用户身份的权限委托。配置导出包含关联与规则，排除消息、游标和投递队列；导入后关联停用，必须重新选择当前宿主会话和任务目标。关联规则按任务名称恢复引用。跨安装的会话 ID 不会静默绑定。

## 隔离启动

「Yu 今日」是默认首页，任务位于第二个导航入口。记忆整理使用一个普通「记忆维护」任务，启停、触发规则和历史都在任务详情中管理；新会话开始前只同步短期记忆，夜间定时或手动运行按该任务的长期策略筛选稳定事实、偏好、关系和约定。整理提示全部在维护任务目标中编辑，模型只输出正文，不再输出 JSON。新会话一次调用更新唯一关联的短期文件；手动或夜间有长期资料且开启长期整理时，再调用一次模型按来源编号筛选原文引用。两阶段校验成功后一起提交；失败保留原记忆与游标。旧配置有多个短期文件时，在任务详情明确选择输出文件，其他文件保留。长期整理可关闭，也可在任务目标中编辑筛选说明及设置每批最多保留的条数（1–12，默认 8）；这是本批材料的筛选上限，未选中的已审阅材料不会自动成为下次待办。关闭长期整理不消费其来源，重新开启后仍可处理积压。

长期候选必须引用用户消息中的连续原文，作为「用户自述」存储；助手回复和没有原文依据的推测不入库。记忆详情保留原文、会话或 DSH 事件定位。重复原文在全库去重，已有核心和长期条目不自动覆盖；不同表述、否定和更正可能保留为不同条目。模型筛选不能替代事实核实。短期与长期分别记录已处理来源，避免白天短期同步后夜间漏掉长期来源；模型、校验或数据库写入失败不推进游标。提交后的文件投影或宿主归档若失败，会明确报错，重试修复而不重复提取。

先安装并使 dsh 命令可用，在本目录执行：

```sh
node scripts/start-isolated.mjs
```

默认管理台 http://127.0.0.1:58810/ ，DSH http://127.0.0.1:30810/ ，独立数据 ~/yu-isolated 。可通过 YU_REPRO_ROOT、YU_PORT、YU_DSH_PORT、DSH_BIN 自定义。不要选择已有部署的数据目录。退出按 Ctrl+C。

首次使用终端或数据目录 pairing-code.txt 的配对码登录，在「初始化」中选择「使用已有 DSH 会话」或「Yu 管理会话」，明确选择接入、私聊好友和群聊对象，再预览并应用。已有会话模式需授权读取所选历史，并点击首次长短期记忆构建；成功前业务保持暂停。维护在独立内部会话进行。Yu 管理模式每次业务新建会话，成功后维护记忆并归档，失败会话保留。默认仅提供早安、晚安、自由活动、私聊、群聊、日记和记忆维护七项角色；新装模板暂停，定时输出默认留在会话内。不要自动导入旧配置；资料库按需手动导入。

模型调用需要在这个独立 DSH 的设置中填写供应商/API密钥，再在 Yu 设置中选 provider/model（留空沿用宿主默认）。没有密钥时不能与模型对话。QQ、SMTP、知识库需自行配置账号、凭据或数据。所有修改的生效时间见管理台和[配置说明](docs/CONFIGURATION.md)。

## 配置与清空

JSON支持merge合并与replace全覆盖：merge省略的领域或实体保留，replace清空运行配置后应用完整文档。用户行为配置由单份JSON配置；宿主API密钥、端口、数据根由DSH与启动配置管理。导出凭据需明确勾选。

设置→配置→清空运行配置恢复运行设置并清空注入资源定义；删除任务、上下文、项目定义、渠道与工具覆盖。保留聊天、归档、记忆、独立人格文件、设备登录、可恢复的项目进度。清空前先备份，恢复方法见[配置说明](docs/CONFIGURATION.md)。

## 开发

```sh
npm test
npm run check
npm ci --prefix web
node web/node_modules/typescript/bin/tsc --noEmit -p web/tsconfig.json
npm run build:web
```

Windows临时目录权限失败时，把 TMP 与 TEMP 都设到可写目录。发布已含 dist/web，无需构建即可运行。

这是原开发工作区按白名单抽取的全新发布快照，未含原数据库、个人角色卡/会话导出、日志、账号配置或历史Git记录。无远端、未推送。测试替身仅用于可重复验证，不代表真实外部API已接通。

更多自定义维护、具名知识库与OneBot配置见 [扩展配置说明](docs/EXTENSIONS.md)。

独立触发器、泊松随机与Roll点的规则、时间窗口和持久化语义见 [触发器说明](docs/TRIGGERS.md)。

群聊观察可选择「关键词或累计条数」：明确选定接入和群后，叫到任一关键词或累计到指定条数（默认20）就查看一次，两个条件同时命中也只启动一次任务。计数按触发绑定、接入、群独立持久保存；去重消息和机器人自身消息不计入。查看携带该批近期消息，每条最多200字符；模型只输出 `%%` 表示保持安静，否则最多发一条回原群。现有直接 @ 回复优先，成功入队会重置这一批累计，避免同条再次观察；入队失败保留批次。修改规则或启停该绑定会清空旧累计，重启本身不会清空。新规则不主动读取历史或自动启用现有停用任务。

资源文件映射、任务注入选择和兼容迁移见 [框架说明](docs/FRAMEWORK.md)，外部数据库适配器技术操作见 [适配器说明](DATABASE-SOURCES.md)。个人记录和外部资料统一在「记忆 → 长期记忆库」管理。

长期记忆库接受个人 SQLite 文件或外部资料清单路径，先显示数量、重复和冲突，再确认导入。个人导入只合并 memories、memory_edges、memory_documents，保留 ID、时间、状态和来源；不导入聊天、任务或配置，不覆盖内容冲突及同名文档。导入前创建一致备份，重复导入不新增。结果中的批次撤销只移除本批尚未修改、且不被后来记录引用的新增内容。原文件保留。历史归档引用可能只保留标识，不额外导入私有归档。

库列表提供状态、数量、使用处、路径和策略。外部资料按只读适配器引用，可修改路径、启停或移除，原文件不删除。「允许自动积累」只控制维护任务新增长期记录，手动保存和日记仍可使用。个人库停用保留全部记录。尚不支持文本检索的通用 SQL 适配器会明确显示限制，高级查询继续兼容。

在库的「使用处与策略」直接选择上下文，或在上下文方案选择「允许检索的长期记忆库」。未设置时仅检索个人库，显式空列表不检索任何库；选择外部库是独立的检索授权，不要求开放 SQL 工具。关闭库或检索策略即时阻止后续检索；已建立会话的上下文沿用其既有快照，新会话使用新设置。检索只加入带库名和来源的相关片段，不把全部资料注入模型。

任务按实例与操作授权、资源依赖替换/解绑和逐次运行诊断见 [资源组合说明](docs/RESOURCE-COMPOSITION.md)。

任务绑定会话、临时会话自动关闭及长期会话摘要接续见 [会话生命周期说明](docs/conversation-lifecycle.md)。


### 在页面上配置常用触发与模板

任务 → 新建任务提供定时任务、聊天桥、随机活动、群聊响应四种模板。定时可填时间、星期、时区或间隔；随机可设置平均等待、冷却、活动窗口及 Roll 点。聊天桥选择接入名称和私聊对象；群聊响应必须填写目标群号，可选真实 @我、关键词、前缀、命令或全部消息。QQ 官方群对象使用平台提供的群 openid。未配置接入时先到接入页添加。

同页选择目标、输入、上下文、任务会话与输出路由。消息任务可回复原来源或仅保存在任务会话；定时与随机结果保存在任务会话。新建默认停用，保存不会立即运行；确认后在任务列表打开启用。若勾选创建后启用，保存后即可按规则执行。私聊仍遵循主人和陌生人回复设置。

任务 → 触发器 → 编辑规则可以直接修改常用字段，JSON 收在高级参数。规则为共享定义，修改会同步到所有引用任务，各任务的等待时刻与运行记录独立；任务详情管理引用和本地暂停。随机与 Roll 显示概率节奏，未来触发时间为各实例已抽取时刻，不保证固定频率。每条规则的时区留空时继承运行时区。

新建任务、绑定和自动创建共享规则同一事务提交；保存失败不残留半个任务。已有规则的扩展字段与配置导入导出保持兼容。
